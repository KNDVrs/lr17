Лабораторная работа №17. Внедрение зависимостей с помощью Hilt
Тема: Введение в dependency injection на Android. Настройка Hilt, базовые аннотации и внедрение зависимостей.

Цели работы
Изучить назначение dependency injection (DI) в Android-приложениях.

Настроить и подключить библиотеку Hilt в существующий проект.

Освоить использование базовых аннотаций: @HiltAndroidApp, @AndroidEntryPoint, @Module, @InstallIn, @Provides, @Inject.

Внедрить через Hilt ключевые зависимости (репозиторий, база данных Room) в компоненты приложения.

Краткие теоретические сведения
Dependency Injection (DI) — это подход в программировании, при котором объект не создает свои зависимости самостоятельно, а получает их извне. Это снижает связанность кода, упрощает тестирование и облегчает замену реализаций (например, подстановку тестовой базы данных вместо реальной).

Hilt — это DI-фреймворк для Android, созданный поверх Dagger. Он автоматизирует создание графа зависимостей и привязывает его к жизненному циклу стандартных компонентов Android (Activity, Fragment, ViewModel).

Описание структуры DI в проекте
В ходе выполнения лабораторной работы в проект были внесены следующие изменения:

Настройка уровня приложения: Создан класс приложения, помеченный аннотацией @HiltAndroidApp. Это позволило Hilt генерировать необходимый код для управления зависимостями на уровне всего жизненного цикла приложения. Класс зарегистрирован в файле AndroidManifest.xml.

Создание DI-модулей: Реализован модуль для работы с данными (например, DatabaseModule), помеченный аннотациями @Module и @InstallIn(SingletonComponent::class). Это обеспечило доступ к объектам базы данных во всем приложении.

Описание поставщиков зависимостей: Внутри модуля добавлены методы с аннотацией @Provides. Они описывают для Hilt правила создания экземпляра базы данных Room и объектов доступа к данным (DAO).

Внедрение в UI-компоненты: * Классы Activity и Fragment помечены аннотацией @AndroidEntryPoint, что позволило им автоматически получать нужные зависимости.

Классы ViewModel переведены на использование аннотации @HiltViewModel, а их конструкторы помечены @Inject для автоматического получения репозиториев.

Ход выполнения работы
В файлы конфигурации build.gradle добавлены плагины и зависимости Hilt.

Проведена инициализация Hilt в пользовательском классе Application.

Созданы модули для предоставления объектов базы данных и DAO, которые нельзя создать через обычный конструктор.

Выполнена рефакторизация кода: удалено ручное создание экземпляров базы данных и репозиториев в Activity и ViewModel.

Проведена проверка работоспособности: приложение успешно компилируется, зависимости внедряются без ошибок.

Выводы
Внедрение Hilt позволило автоматизировать процесс управления зависимостями. Это значительно улучшило чистоту кода, так как логика создания объектов теперь отделена от логики их использования. Проект стал более масштабируемым и удобным для дальнейшего тестирования.
